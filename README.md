# CampusConnect 🚀

##  Sobre o Projeto
[cite_start]O **CampusConnect** é um aplicativo desenvolvido para simplificar, organizar e centralizar a gestão de eventos acadêmicos [cite: 33] (como semanas de tecnologia, palestras, workshops e hackathons). O sistema visa integrar os organizadores, palestrantes e alunos em uma única plataforma, facilitando desde a inscrição até a emissão de certificados.


---

##  Objetivo
[cite_start]Resolver a descentralização das informações de eventos no campus[cite: 33], permitindo que os organizadores gerenciem salas e horários, e que os alunos descubram atividades, realizem inscrições e registrem presença de forma automatizada.

##  Ferramentas Utilizadas no Ecossistema Ágil
[cite_start]Para simular o ambiente de trabalho de uma equipe ágil profissional, configuramos as seguintes ferramentas[cite: 11]:

* [cite_start]**Gestão de Tarefas (Kanban):** `Trello` [cite: 45] - [cite_start]Utilizado para organizar o fluxo de trabalho através das colunas Backlog, To Do, Doing e Done [cite: 51][cite_start], permitindo o acompanhamento visual do progresso das atividades[cite: 41, 42].
* [cite_start]**Versionamento:** `GitHub` [cite: 60] - [cite_start]Utilizado para o controle de versão do código-fonte, histórico de alterações e garantia de rastreabilidade do projeto[cite: 57, 58, 200].
* [cite_start]**Documentação:** `Google Docs` [cite: 73] - [cite_start]Central de conhecimento para registrar a visão do produto, regras iniciais, requisitos e decisões técnicas importantes[cite: 70].
* [cite_start]**Comunicação:** `WhatsApp (Comunidades)` [cite: 91] - [cite_start]Canal oficial para alinhamento rápido da equipe, avisos gerais e tomada de decisões, reduzindo falhas de comunicação[cite: 85, 95, 201].
